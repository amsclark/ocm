%%[sso_single_logout,yes_no,checkbox,label=End the Provider Session on Sign-Out]%%
Sends the user to the identity provider to sign out there as well, so the next sign-in asks for credentials again. Register this installation's address as a post-logout redirect URI at the provider before turning this on, or the provider will show an error instead of returning the user. Providers that do not publish an end-session endpoint, Google among them, ignore this.
